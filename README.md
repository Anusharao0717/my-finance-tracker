# My Finance Tracker — Android App

A mobile-first personal finance tracker built with React, TypeScript and Capacitor.

## Features

- Monthly income
- Car loan tracking
- Credit card tracking
- Gold loan tracking
- Add/edit/delete payments
- Paid/Pending status
- Due dates
- Payment progress
- Remaining balance
- Offline storage
- Dark mode
- Android local payment reminders

## Requirements

Install:

1. Node.js LTS
2. Android Studio
3. Android SDK
4. Java/JDK supported by your installed Android Studio

## Install

Open a terminal in this project folder:

```bash
npm install
```

## Run in browser

```bash
npm run dev
```

## Create Android project

```bash
npx cap add android
```

Then:

```bash
npm run build
npx cap sync android
npx cap open android
```

Android Studio will open the project.

## Run directly on an Android phone

Enable Developer Options and USB debugging on the phone, connect it to the PC, then in Android Studio select the phone and press Run.

You can also use:

```bash
npm run build
npx cap sync android
npx cap run android
```

## Build APK

In Android Studio:

Build → Build Bundle(s) / APK(s) → Build APK(s)

The debug APK can then be installed on your phone.

## App ID

```text
com.anusharao.myfinancetracker
```

## Data

Finance data is stored locally on the device/browser. No server or account is required.

## Important

The Android folder is generated by Capacitor so it matches the Android SDK/Gradle environment on the machine. Run:

```bash
npx cap add android
```

once after installing dependencies.
